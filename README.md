# Pipeline

Mini CRM de prospection mono-utilisateur. Voir [INTENT.md](./INTENT.md).

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS · shadcn/ui · Vitest · pnpm

## Démarrer

```bash
pnpm install
pnpm dev     # http://localhost:3000
pnpm test    # smoke test
pnpm lint
pnpm build
```

## Branches

- `main` : production
- `dev` : branche de travail
